# DotGhostBoard 2.1.2

Prepared 2026-10-06.

## Changes

- Existing Vault secrets are excluded from clipboard history and new-secret prompts.
  Confirmed matching history entries are removed, including pinned entries.
- A non-empty Vault must be unlocked once after application startup before text
  can be checked. Recognition continues after auto-lock without retaining its encryption key.
- Desktop notifications have master, security, update, and sound controls in Settings.
  Notification actions use asynchronous Qt D-Bus with delivery fallbacks.
- PRIMARY capture respects pause, preserves existing/pinned clips during consolidation,
  and keeps the first external copy after selection synchronization.
- Settings layout and custom sound cancellation are corrected.
- Native and Python packages include runtime icons and sounds only, excluding local data.
- Includes the preceding PRIMARY selection, audio feedback, and Vault CSV import work.

## Verification

- Full suite: 589 passed (Python 3.14.7, headless Qt).
- Isolated D-Bus probe: notification delivered; delayed action ran on the GUI thread.
- Built x86_64 AppImage, DEB, Arch package, and portable tarball.
- Native binary and extracted AppImage launched with isolated profiles, IPC and
  discovery active, then shut down cleanly.
- All four package checksums verified; see `2.1.2.sha256`.
- Verified native runtime assets and QtDBus inclusion; DEB metadata is version 2.1.2.
- Python wheel built from a clean staging directory and checked for runtime-only data.
  The build used installed setuptools with dependency checking skipped because the
  separate wheel distribution is unavailable in the build environment.

## Remaining release checks

Visually exercise mouse selection, notification actions, and Vault protection on the
actual desktop, including one cold start with a locked Vault. Headless checks do not
certify every compositor or distribution. Packages are built on this host; installation
on other Linux distributions has not been tested here.

GitHub publication and signing are separate from this local release preparation.
