# DotGhostBoard v2.1.3 — Vault Recovery & Security

This release adds encrypted recovery copies and an optional independent Vault
password, and restores clipboard capture immediately after session authentication.

## What's new

- **Backup & Recovery:** choose specific Vault items or all-items Auto Sync, keep
  a live encrypted copy and daily/weekly/monthly versions, and select a backup folder,
  passphrase, and retention count. Safety copies precede destructive changes.
- **Verified restoration:** preview authenticated `.dgb-recovery` and `.vault` backups,
  restore the current Vault while preserving its original files, or recover into a
  new profile even when the original profile and credentials are unavailable.
- **Optional separate Vault password:** enable it in Settings → Eclipse. Independent
  mode uses Argon2id and asks for the Vault password immediately after Dashboard
  authentication. Shared-password mode remains the default.
- **Stronger encrypted records:** titles, categories, expiry, and secret/history
  payloads are authenticated and encrypted. New manual backups use Argon2id; older
  backup imports remain supported.
- **Reliable capture and locking:** unified unlock initializes Vault secret recognition
  before capture resumes. Imported CSV password components stay out of Dashboard
  history. Dashboard auto-lock is optional and disabled by default.
- **Recovery UI polish:** search and select visible results in bulk, and run setup,
  copying, verification, and restoration in background workers with progress and
  protection against duplicate actions.

## Upgrading

Before upgrading, close DotGhostBoard and keep a complete, consistent copy of your
profile (`ghost.db`, `vault.db`, `eclipse.salt`, and `eclipse.verify`), or export a
readable encrypted Vault backup. Successful unlock migrates the Vault to schema 2;
older application versions cannot open the upgraded database.

Recovery requires an existing readable backup and its passphrase. Scheduled copies
run while the application and Vault are unlocked and catch up on the next unlock.

- [Recovery setup and restoration guide](https://github.com/kareem2099/DotGhostBoard/blob/v2.1.3/docs/vault-recovery.md)
- [Security model and migration notes](https://github.com/kareem2099/DotGhostBoard/blob/v2.1.3/docs/security-model.md)
